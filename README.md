# DisplayHub Android Player

Cliente Android/Android TV oficial do DisplayHub.

Objetivo da V1: provisionamento por link/token, player WebView em tela cheia, manter tela ativa, recuperação automática, inicialização no boot, heartbeat e comandos remotos com confirmação de execução.

O painel web continua no repositório `Mgteixeira2112/displayhub`. Este repositório contém apenas o player Android.
